Horizon Convert.

Inspect a downloaded JAR or ZIP, edit the Horizon manifest, and export a content package.

⇄
!
Important: this is a content packager, not a Java code port.

Fabric / Forge Java classes cannot be made into Horizon code by renaming a file. This tool carries over assets/ and data/ files only. Their formats still need to be compatible with Horizon.
